# Experiments

Disposable research prototypes and their findings. Everything in this folder
is reference material, not a source of truth.

How to treat this folder:

- Each experiment's `findings.md` records what it established. Read it before
  the code; the code exists to back the findings.
- Findings are evidence, not decisions. They tell you what was proven or
  disproven at the time, under assumptions that may no longer hold.
- Nothing here is production code. Do not import from it, extend it, or treat
  its APIs as designs to copy. Production work starts from a clean foundation
  and uses these as reference implementations.
- Findings are a historical record. Do not edit them. New evidence belongs in
  a new experiment with its own `findings.md`.
